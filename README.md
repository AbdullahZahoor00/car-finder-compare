# car-finder-compare


Search a car dataset (model years 2000–2026) in plain English, sort the results
(cheapest, lowest mileage, newest) or compare two cars side by side.
Built with Python and pandas in a Google Colab notebook. Nothing needs to be installed.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/AbdullahZahoor00/car-finder-compare/blob/main/car_finder_compare_colab.ipynb)

## How to run
1. Click "Open in Colab".
2. Click **Runtime → Run all**.
3. Type in the search box, for example `cheapest Toyota Corolla` or `Corolla vs Civic`.
